
# RelayProof Documentation

Welcome to the RelayProof developer documentation.

RelayProof is an independent software-verification platform for AI coding agents and developers.

It provides artifact-bound verification evidence through a structured ProofPack.

## Current Development Status

RelayProof is in early MVP development.

Completed:

- Public landing page.
- Initial documentation interface.
- React/Vite/TypeScript frontend.
- Fastify backend foundation.
- Health-check endpoint.

Currently being developed:

- PostgreSQL configuration.
- Prisma integration.
- Database models.
- Task management API.

Planned:

- Functional dashboard.
- Submission workflow.
- Verification engine.
- ProofPack generation.
- Cryptographic attestations.
- BNB Chain integration.

## Core Principle

Evidence over assertion.

RelayProof must clearly distinguish implemented features from planned capabilities.
